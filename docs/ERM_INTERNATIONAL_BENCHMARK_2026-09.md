# ERM 国际对标评估（2026-09）

## 结论（董事会可读）

| 维度 | 国际一线（Big4 / 全球银行 ERM） | 本系统现状 | 差距 |
|------|----------------------------------|------------|------|
| 方法论 | ISO 31000 + ISO 31010 + COSO，独立 P×I 矩阵 | 规则引擎 + 独立热力图字段 + 贝叶斯更新 + 4T 方案包 | **接近**；缺独立模型验证文档与第三方认证 |
| 数据与证据 | 商业工商/司法 API、审计轨迹 | 天眼查/企查查适配层 + 演示样例 + 人工勾选门禁 | **中等**；生产需配置 `TIANYANCHA_TOKEN` |
| 动态与闭环 | 版本 diff、KRI、复评触发 | **多期风险矩阵**、`assessment_diff`、闭环/KRI/任务 | **良好** |
| 解决方案 | 治理路线图、董事会决议项 | `solution_program`（4T、90 天、board asks）+ 深度方案库 | **良好** |
| 交付物 | PDF/DOCX/数据交换 | Word/PDF/HTML/MD/JSON + 解决方案 Word/JSON + Bridge HTML/DOCX | **良好**；缺原生 PPTX、XBRL |
| 英文与国际 | 全球董事会包 | **Executive Summary (EN)** + 框架标注 | **入门**；全文多语与 IFRS 风险披露模板待补 |

**总评**：在「咨询交付 + 动态企业评估」场景下，已达 **国际先进（upper-mid）**，尚未稳定进入 **全球顶尖投行/跨国集团总部** 所要求的「模型治理 + 全量外源 + 多实体合并 + 监管报送」层级。

## 使用建议

1. 每次评估勾选 **保存历史**，仪表盘查看 **风险变化矩阵**。
2. 配置商业外源后，报告「外部证据」区块方可支撑尽调级表述。
3. 董事会外资成员可直接引用 **Executive Summary (EN)**；正式对外仍建议人工审校。
