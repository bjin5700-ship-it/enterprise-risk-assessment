### C3 · 独立 5×5 可能性 × 影响 ✅ 已上线（2026-08-21）

- **问题**：P 与 I 都由同一 `score` 推导，不能当 ISO 31010 矩阵。
- **做法**：
  - 每个关键风险项增加独立字段：可能性 1–5、影响 1–5（可默认建议值，但允许覆盖）。
  - `build_heatmap_matrix` 只使用独立字段；规则分仍用于综合评分。
  - 报告第十七章注明「矩阵来自独立估计，综合分来自规则引擎」。
- **涉及**：`risk_matrix.py`；Excel/Web 模板字段；`risk_analytics.py`；`risk_deep_analysis.py`；报告前端
- **验收**：同一维度下可出现「分高但矩阵格不同」的组合；不再出现 P=I=f(score) 的硬编码。
- **落地**：各评分表增加「可能性(1-5)」「影响(1-5)」；未填用建议值并标灰。DEMO 财务 P3×I5、人力 P5×I2。生产已同步。

### C4 · 蒙特卡洛双轨 + 敏感性 ✅ 已上线（2026-08-21）

- **问题**：当前 MC 是分数高斯扰动，VaR 文案像金额损失。
- **做法**：
  - 分数轨：保留现有扰动，文案改为「综合评分不确定性区间」，禁止「尾部期望损失」措辞。
  - 金额轨（可选）：若填了收入/资产，用简单冲击（收入下滑%、或有负债）输出金额 P10/P50/P90；未填则隐藏金额轨。
  - 主仓库已有 NumPy；补 SALib，报告增加「对综合分贡献最大的 5 个假设」。MC 实现仍是分数高斯扰动，文案必须先改。
- **涉及**：`risk_quant.py`；`requirements.txt`；报告「十二、蒙特卡洛」
- **验收**：无金额字段时不出现损失措辞；有金额字段时分数轨与金额轨分开展示。
- **落地**：NumPy 抽样 + SciPy 分位 + SALib Morris μ*；`var_95`/`cvar_95` 仅兼容旧键，UI 显示 P95 评分 / 尾部均值评分。生产已同步。

### C5 · 合规/信用外部证据 ✅ 已上线（2026-08-21）

- **问题**：诉讼、失信、处罚依赖自填，动态性不足。
- **做法**：
  - 适配层：统一社会信用代码 → 外部记录（诉讼/失信/处罚/经营异常）→ 证据表（来源、日期、原文摘要、URL）。
  - 数据源：商业 API（天眼查/企查查等）或可配置的 MCP/HTTP；无密钥时跳过并在报告标明「未接外部源」。
  - 评分：外部命中作为加分证据，不覆盖规则引擎，需人工勾选后写入（沿用现有证据候选交互）。
- **涉及**：`data_external_risk.py`；数据录入页证据区；合规/信用 scorer
- **验收**：演示企业可注入样例外部证据并在报告合规章展示来源；无 API Key 时系统仍可评估。
- **落地**：`/api/external-risk`；无密钥标明未接外部源；DEMO 注入样例诉讼/处罚。生产已同步。
